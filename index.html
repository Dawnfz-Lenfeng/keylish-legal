键语 Keylish 支持

中文拼音键盘 · 可选的英文译文对照

开启键盘

  1. 打开「设置」→「通用」→「键盘」→「键盘」→「添加新键盘」，选择「键语」。
  2. 如果要使用译文对照，点进「键语」开启「允许完全访问权限」。
  3. 在任意输入框长按地球键切换到键语键盘。

常见问题

  • 键盘不显示译文？请在系统设置中为键语开启「允许完全访问权限」，译文对照需要它才能访问 Apple 系统翻译。
  • 中文输入要付费吗？不需要。中文、ABC、数字、符号和表情输入始终免费；试用或解锁只影响译文对照。
  • 换了设备或重装后解锁没了？在 App 内的译文对照页面点「恢复购买」。
  • 试用结束后会自动扣费吗？不会。终身解锁是一次性购买，没有订阅。

Support (English)

  1. Settings → General → Keyboard → Keyboards → Add New Keyboard → Keylish.
  2. For translation comparison, open Keylish in that list and enable Allow Full Access.
  3. Long-press the globe key in any text field to switch to Keylish.

Chinese, ABC, numeric, symbol, and emoji input are always free; the trial or unlock only affects translation comparison. Payments are one-time — there is no subscription. Restore purchases from the translation access screen. Questions or feedback: GitHub Issues.
